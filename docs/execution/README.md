# Kastur V2 Execution Registries

This directory contains the operational execution state for Kastur V2.
These are registries tracking implementation state, not primary business rule authorities.

For business rules and architecture authority, refer to the root `docs/` and `docs/decisions/`.

## Registries

- **MILESTONE_STATE.md**: Tracks completion, commits, and dependencies of major milestones.
- **ACCEPTANCE_REGISTRY.md**: Master index of tested capabilities.
- **SCHEMA_VERSION_REGISTRY.md**: Historical record of schema updates and migrations.
- **ERROR_CODE_REGISTRY.md**: Standardized error codes across applications.
- **DOMAIN_OWNERSHIP.md**: Ownership boundaries of Kastur domains.
- **EXTERNAL_GATES.md**: Tracking external dependencies that block autonomous progression.
